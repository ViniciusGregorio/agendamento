# Botica Belladonna

Landing page responsiva desenvolvida a partir da identidade pública da Botica Belladonna.

## Rodar localmente

Sem instalar nada:

```bash
python3 -m http.server 4173
```

Depois, abra `http://localhost:4173`.

Ou, com Node.js:

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
